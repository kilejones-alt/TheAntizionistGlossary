# The Antizionist Glossary

Live site: https://kilejones-alt.github.io/TheAntizionistGlossary/

## Update an entry

1. Edit the relevant English or Hebrew `.html` file. Keep citations attached to the claims they support.
2. Run `node scripts/check-site.mjs` from this folder. It checks all 91 pages, local links, browser policies, and the original app links.
3. Commit and push to `main`, then open the changed page on the live site. GitHub Pages publishes changes from its configured source branch; allow a few minutes for the update to appear.

The original Antizionism Detector reads glossary text when a term opens. A text-only glossary update does not require a Netlify or Google Play release. The app's own source and release instructions are in [antizionism-detector-app1](https://github.com/kilejones-alt/antizionism-detector-app1).
